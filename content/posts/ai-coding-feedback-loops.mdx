AI can generate extraction code quickly, but quality comes from loops.

A simple loop:

1. Draft parser with AI.
2. Run on messy real samples.
3. Review failures and annotate edge cases.
4. Regenerate tests and parser updates.

Short iterations beat heroic rewrites.
